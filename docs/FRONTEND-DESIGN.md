# 前端设计与实现

Vue3应用共用品牌与控件，用户端、商家端、管理端保留独立布局。用户端是蓝白校园布告栏，经营和管理工作区保持紧凑。

## 颜色、字体与密度

基础变量位于frontend/src/campus-styles/tokens.css：校园蓝#2055ce、深蓝#1744a8、浅蓝#edf3ff、黄色#ffdf7e、少量橙色#a9421d、墨色#202a3c、页面底色#f6f8fc。正文主要13/14px，辅助元信息12px，金额使用等宽数字特性。

静态学生标题使用自托管Campus Notice Round，400字重；源于寒蝉圆体OFL派生子集。字体已更名，来源、许可与子集说明随前端public/fonts保留。font-display:swap；正文、金额、表单、动态优惠标题和authored-title帖子标题使用系统无衬线，避免静态子集造成用户内容字形混排。

## 布告栏与信息

优惠采用桌面双列／手机单列票据，金额、规则、有效期、库存和领取动作保持相邻。便签连接真实关键词查询、附近商家和社区。统计明确是当前加载页，不伪造全站热度。

统一CampusOrnament提供图钉、回形针、印章、星芒和少量手绘箭头；胶带只作少量点缀。装饰对辅助技术隐藏、不参与点击，不遮挡文字和控件。

## 分层footer

CampusFooter使用独立景物背景和透明人物图片。背景宽高100%、object-fit:cover，13%不透明度；人物等比缩放、24%，不拉伸。顶部82px页面底色到透明的覆盖层只作用于背景，人物在其上保留清晰度。文字和三个原有链接在前景，页脚高度由内容决定，图片不另占展示带。

WebP素材和生成提示词JSON随前端src/assets保存。景物／人物图片分别可替换，不把两者合成后缩成中间小块。图片为装饰，不代表真实校园或活动。

## 交互与验证

领取撕票只在服务端确认成功后播放；等待中、失败不播放。减少动态效果时直接显示确认，离开页面清理计时器。切页不无条件重挂载账号表单。菜单具有展开状态和键盘焦点反馈。

浏览器夹具检查覆盖1440/768/390页面和320–2560页脚，验证加载、覆盖、人物比例、无额外高度及动态帖子标题字形；夹具不代表真实数据库或供应商验收。

- 地图作为页面主体，搜索盒子嵌入地图右下角；桌面经纬度、搜索半径、商家类型横排，放大镜查询按钮位于输入框左侧。
- 手机输入框采用两列两行，定位按钮嵌入盒子右上空位，放大镜位于其下方；不再单独占用地图区域。
- 去掉“找一找附近”等额外标题、宣传语和提示标签；保留输入标签、无障碍按钮名称、键盘提交和必需的错误反馈。
- 桌面定位图标在搜索条上方，手机收进搜索盒子；仅点击定位按钮时申请浏览器位置授权。助手入口在本页移至左下角，离开后复位，避免遮挡地图操作。
- `AmapView` 增加可选沉浸布局，默认商家门店地图布局保留。SDK 加载器、地图初始化、WGS84 转换、标记更新与销毁逻辑均与改版前一致；SDK 和业务接口未替换。
