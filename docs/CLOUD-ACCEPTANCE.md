## 构建验证

`mvn -Pexternal-sdks verify` 在 Java 17 上通过：本次 Surefire 汇总 262 项，其中执行 30 项、按条件跳过 232 项，失败和错误均为 0。跳过项包含需要显式授权数据库／外部服务测试开关的专项，**不计作本次通过**。首次受限运行环境不能使用本地测试端口，适配器测试未能运行；在允许测试回环端口的环境重跑后通过，不把该环境错误记成业务缺陷。

`npm run build` 通过，包含 Vue／TypeScript 类型检查和生产构建。未升级项目 Java/npm 依赖。本次部署 JAR 摘要 `aa6f1cc6f1150462f8c7043e11a4f59e8b570429852fc94764a2dd0b4f2e8bb0`，前端部署归档摘要 `b9e57c9e5ffc3ac6ca45a3df66e674ba832591178d041c26a043432241bee4b0`；这些是已部署归档，后续重新构建的归档时间戳可能不同。
